⚙️ API-Konfiguration

Nutze OpenAI, OpenRouter oder einen kompatiblen Endpoint. Der Schlüssel wird nur lokal gespeichert.

Wird verschlüsselt im LocalStorage gespeichert. Für Tests kann auch ein temporärer Key verwendet werden.

Leer lassen für OpenAI. Für OpenRouter: https://openrouter.ai/api/v1

Empfohlen: gpt-4o-mini oder gpt-3.5-turbo

0.0 = sehr deterministisch, 0.7 = kreativer Dialekt. Standard: 0.3

🛠️ Technik-Stack

Moderne Technologien für maximale Performance

⚙️ Pipeline

  • 🎤
    STT: Whisper (lokal für Batch, Deepgram Fallback)
  • 🤖
    LLM: GPT-4 via Backend-Proxy + Dialekt-Regelwerk
  • 🔊
    TTS: ElevenLabs Realtime, Fallback Piper offline
  • 💻
    Backend: Node.js + Express, WebSocket für Streaming

🔒 Sicherheit & Privacy

  • ✓
    Keine Speicherung von Audiodaten
  • ✓
    Anonymisierte Logs, Rate Limits
  • ✓
    API-Keys ausschließlich im Backend
  • ✓
    CORS für definierte Origins
