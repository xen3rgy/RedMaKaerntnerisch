Moderne Technologien für maximale Performance

⚙️ Pipeline

  • 🎤
    STT: Whisper API (OpenAI, "whisper-1") für Transkription
  • 🤖
    LLM: Chat Completions (OpenAI/OpenRouter) + Dialekt-Lexikon/Beispiele/Regelwerk
  • 🔊
    TTS: ElevenLabs API (Text-to-Speech) für Dialekt-Ausgabe
  • 💻
    Backend: im Demo-Prototyp nicht enthalten (geplant: Proxy/Streaming)
